01. 原生双轨标注语法

开箱同时支持 ::: info / tip / warning / danger / details 自定义容器与 GitHub 风格 > [!NOTE] 警报块，并内置全局 组件。

02. 插件化 Mermaid 11 渲染

原生不解析 mermaid 代码块；通过 vitepress-plugin-mermaid@2.0.17 包装配置接入 mermaid@11.17.2（尚未放开 mermaid@12 peerDependency）。

03. 构建期 MathJax 3 矢量公式

配置 markdown: { math: true } 并安装 markdown-it-mathjax3@4.3.2 即可在构建期直接产出内联 SVG 公式，客户端零运行时开销。

04. 浅平铺目录与纯手写侧边栏

支持零层级平铺但需手动配置 srcExclude: ['README.md'] 防误编译；无内置自动侧边栏，多级嵌套需手写维护 config.mts。
